# Sistema de Agência Solo — Marketing Digital com IA

> Operação completa de uma agência de marketing de uma pessoa, automatizada com Claude + Canva.

## Estrutura do Sistema

```
sistema/
├── 01-aquisicao.md         → Como atrair e converter leads
├── 02-producao.md          → Fluxo de criação de conteúdo com IA
├── 03-entrega.md           → Processos de entrega padronizados
├── 04-retencao.md          → Converter pontuais em mensais
modelos/
├── proposta-comercial.md   → Template pronto para enviar
├── calendario-conteudo.md  → Planilha de 30 dias de conteúdo
├── relatorio-desempenho.md → Relatório mensal do cliente
├── pacotes-servicos.md     → Ofertas mensalizadas prontas
automacoes/
├── prompts-claude.md       → Prompts prontos para cada tarefa
├── fluxos-canva.md         → Fluxo de design acelerado
rotinas/
└── semana-otimizada.md     → Rotina semanal completa
erros-comuns.md             → O que evitar desde o início
```

## Os 4 Pilares do Sistema

| Pilar | Objetivo | Tempo/semana |
|-------|----------|-------------|
| Aquisição | Gerar leads qualificados | 3h |
| Produção | Criar e entregar conteúdo | 15h |
| Entrega | Comunicação e relatórios | 4h |
| Retenção | Manter e upsell clientes | 2h |

**Total: ~24h/semana → Capacidade para 5–8 clientes mensais**

## Stack de Ferramentas (Custo ~R$ 200/mês)

| Ferramenta | Uso | Custo |
|------------|-----|-------|
| Claude Pro | IA principal para texto/estratégia | R$ 100/mês |
| Canva Pro | Design e posts prontos | R$ 55/mês |
| Notion | CRM, calendário, gestão | Grátis |
| WhatsApp Business | Comunicação com clientes | Grátis |
| Google Workspace | Drive, Docs, Sheets, Gmail | R$ 45/mês |
| Later ou Buffer | Agendamento de posts | Grátis (básico) |
