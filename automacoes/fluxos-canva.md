# Automações — Fluxo de Design Acelerado no Canva

## Configuração Inicial (faça uma vez por cliente)

### Passo 1 — Criar Pasta do Cliente
1. No Canva, vá em "Projetos" → "Nova pasta"
2. Nomeie: `[Nome do Cliente] — Posts`
3. Crie subpastas: Feed / Stories / Capas / Miniaturas

### Passo 2 — Criar Kit de Marca
1. Acesse "Brand Kit" no Canva Pro
2. Cadastre para o cliente:
   - **Paleta de cores:** Primária, Secundária, Neutra, Destaque
   - **Fontes:** Título (peso bold), Texto (regular), Destaque (italic ou diferente)
   - **Logos:** Versão colorida, branca, preta (em PNG com fundo transparente)
3. **Tempo:** 20 min por cliente, feito uma única vez

### Passo 3 — Criar Templates Base
Para cada cliente, crie estes templates:

| Template | Dimensão | Uso |
|----------|----------|-----|
| Post Feed - Dica | 1080x1080 | Posts educativos |
| Post Feed - Citação | 1080x1080 | Frases impactantes |
| Post Feed - Carrossel (capa) | 1080x1080 | Capa de carrosséis |
| Post Feed - Carrossel (slide) | 1080x1080 | Slides internos |
| Post Feed - Oferta | 1080x1080 | Posts de promoção |
| Story - Dica | 1080x1920 | Bastidor/dicas |
| Story - CTA | 1080x1920 | Call to action |
| Capa LinkedIn | 1584x396 | Perfil LinkedIn |

## Fluxo de Criação de 1 Post (5 min)

```
1. Abra o template do tipo correto (ex: "Post Feed - Dica")
2. Faça uma cópia: Arquivo → Fazer uma cópia
3. Renomeie: "[Cliente] - Post [Data] - [Tema curto]"
4. Troque o TEXTO (copy gerado pelo Claude)
5. Troque a IMAGEM DE FUNDO (se necessário)
   - Use Canva AI (botão "Gerar imagem") ou
   - Banco de imagens gratuito: Unsplash, Pexels (integrado no Canva)
6. Ajuste cor de destaque se o post tiver tema específico
7. Verifique legibilidade: texto visível em fundo branco e preto
8. Exporte: Compartilhar → Baixar → PNG (alta qualidade)
9. Salve na pasta correta do Drive
```

## Truques para Acelerar no Canva

### Atalhos de teclado essenciais:
| Ação | Atalho |
|------|--------|
| Duplicar elemento | Ctrl+D |
| Agrupar | Ctrl+G |
| Desfazer | Ctrl+Z |
| Copiar estilo | Alt+drag |
| Alinhar ao centro | Selecionar + botão Alinhar |
| Tela cheia | F |
| Adicionar nova página | Ctrl+Enter |

### Funcionalidades que economizam tempo:

**1. Copiar e Colar Estilo**
- Selecione um elemento estilizado
- Clique com botão direito → "Copiar estilo"
- Selecione outro elemento → "Colar estilo"
- Economiza: configurar fonte, tamanho, cor manualmente

**2. Substituição de Texto em Lote (Canva Pro)**
- Em carrosséis: edite o texto do Slide 1 e replique o estilo nos outros
- Use "Magic Resize" para adaptar o mesmo design para Story sem refazer

**3. Magic Resize (Canva Pro)**
- Cria o post no Feed (1080x1080)
- Redimensionar → "Story" (1080x1920)
- Ajuste posicionamento → pronto
- Economiza: criar story do zero

**4. Background Remover (Canva Pro)**
- Use em fotos do cliente (produtos, pessoas)
- Remove fundo automaticamente em 5 segundos
- Coloque sobre qualquer cor ou gradiente do template

**5. Canva AI — Geração de Imagens**
- Prompt: "Foto de [cena] em estilo [moderno/minimalista/editorial], cores [cores do cliente]"
- Gera 4 opções em 30 segundos
- Muito útil para niches sem banco de imagens específico

## Organização de Arquivos no Canva

**Nomeação padrão:**
```
[Cliente] — [Tipo] — [Data] — [Tema]
Exemplo: NombreCliente — Post Feed — 2026-04-15 — Dica Financeira
```

**A cada mês:**
1. Mova posts publicados para pasta "Arquivo [Mês Ano]"
2. Mantenha templates limpos e sem texto específico
3. Exclua versões intermediárias e rascunhos

## Fluxo de Entrega de Design

```
Design criado no Canva
        ↓
Exportar em PNG → Salvar no Drive (pasta "Para Aprovação")
        ↓
Enviar link da pasta para cliente via WhatsApp
        ↓
Cliente aprova ou pede ajuste
        ↓
Se aprovado: mover para "Aprovados" + agendar no Buffer/Later
Se ajuste: abrir o Canva, editar, exportar novamente
```

## Checklist de Design antes de Enviar ao Cliente

- [ ] Texto está legível (tamanho mínimo 24px para mobile)
- [ ] Cores estão na paleta do cliente
- [ ] Logo do cliente está presente (se aplicável)
- [ ] Fundo não concorre com o texto
- [ ] Não há erro de ortografia no design
- [ ] Exportado em PNG (não JPEG para texto)
- [ ] Arquivo nomeado corretamente
- [ ] Salvo na pasta correta do Drive
