# Automações — Prompts Prontos para Claude

> Estes prompts são o coração do seu sistema. Salve-os no Notion e use diariamente.
> Dica: Cole o briefing do cliente no início de CADA conversa nova com o Claude para manter o contexto.

---

## Como Começar Toda Sessão de Trabalho

**Prompt de contexto (cole no início de qualquer conversa):**

```
Você é um especialista em marketing de conteúdo para [nicho do cliente].
Vou te dar o briefing do cliente e você vai me ajudar a criar conteúdo.

BRIEFING DO CLIENTE:
- Nome: [Nome]
- Nicho: [Nicho]
- Público-alvo: [Público]
- Tom de voz: [Tom]
- Objetivo atual: [Objetivo]
- Diferencial: [Diferencial]
- Plataforma: [Plataforma]

A partir de agora, todo conteúdo deve seguir este briefing. Confirme que entendeu.
```

---

## Prompt 1 — Geração de Ideias de Posts (12 ideias em 2 min)

```
Com base no briefing acima, gere 12 ideias de posts para [Instagram/LinkedIn].

Para cada ideia, inclua:
- Tipo de post (educativo, bastidor, oferta, etc.)
- Tema específico
- Gancho sugerido (primeiras 2 linhas)

Organize em uma tabela. Varie os tipos para não ficar repetitivo.
Objetivo do mês: [objetivo].
```

---

## Prompt 2 — Escrever Post Completo

```
Escreva um post completo para [Instagram/LinkedIn] sobre [tema/ideia escolhida].

Siga exatamente este formato:
1. GANCHO (máximo 2 linhas — deve parar o scroll)
2. DESENVOLVIMENTO (3–5 parágrafos curtos, linguagem simples, uma ideia por parágrafo)
3. CTA (call to action específico — não use "saiba mais")

Tom: [tom de voz do cliente]
Tamanho: [curto: até 150 palavras / médio: 200–300 palavras / longo: 300–500 palavras]
Evite: jargão de marketing, frases genéricas, emojis excessivos
```

---

## Prompt 3 — Criar Carrossel (slides em texto)

```
Crie o roteiro de um carrossel de [8–12] slides sobre [tema].

Para cada slide, escreva:
- Slide 1: Capa (título que gera curiosidade, máximo 7 palavras)
- Slides 2–[X]: Conteúdo (1 ideia por slide, máximo 30 palavras por slide)
- Último slide: CTA e @mencão do perfil

Tom: [tom]
Tema: [tema]
Público: [público]
```

---

## Prompt 4 — Roteiro de Reels / Vídeo Curto (30–60 seg)

```
Crie um roteiro para um Reels de [30/60] segundos sobre [tema].

Estrutura obrigatória:
- 0–3s: Gancho visual + fala de abertura (deve prender em 3 segundos)
- 3–25s: Desenvolvimento rápido (3 pontos, 7 segundos cada)
- 25–30s: CTA verbal + texto na tela

Inclua:
- Texto para colocar na tela (legenda de cada cena)
- Sugestão de música (estilo/energia, não nome específico)
- Indicação de cortes e transições

Tom: [tom]. Plataforma: [Instagram Reels / TikTok].
```

## Prompt 5 — Gerar Proposta Comercial Personalizada

```
Crie uma proposta comercial profissional para:

DADOS DO LEAD:
- Nome: [Nome]
- Empresa: [Empresa]
- Nicho: [Nicho]
- Problema mencionado: [O que ele disse na reunião]
- Objetivo: [O que ele quer alcançar]
- Pacote de interesse: [Pacote X — R$ X/mês]

Use este template de estrutura:
1. Abertura que demonstra que você entendeu o problema
2. Diagnóstico da situação atual (use os dados do lead)
3. Solução proposta com entregáveis
4. Investimento e condições
5. Próximos passos

Tom: profissional mas acessível. Máximo 1 página. Sem clichês de vendas.
```

## Prompt 6 — Gerar Relatório Mensal Analítico

```
Analise as seguintes métricas de [Mês] para o cliente [Nome] e escreva um relatório profissional.

MÉTRICAS:
- Seguidores: [antes] → [depois] ([variação]%)
- Alcance: [X]
- Impressões: [X]
- Engajamento médio: [X%]
- Melhores posts: [Post 1], [Post 2], [Post 3]
- Posts publicados: [X]

Escreva:
1. Resumo executivo (2–3 frases, tom positivo e consultivo)
2. Análise dos melhores posts (por que funcionaram)
3. 3 aprendizados do mês
4. 3 recomendações para o próximo mês
5. Encerramento motivador

Tom: consultivo, data-driven, positivo mesmo quando resultados foram abaixo do esperado.
```

## Prompt 7 — Otimizar Texto do Cliente para SEO

```
Otimize este texto para SEO mantendo o tom natural:

TEXTO ORIGINAL:
[Cole o texto]

PALAVRA-CHAVE PRINCIPAL: [palavra-chave]
PALAVRAS-CHAVE SECUNDÁRIAS: [palavra 1], [palavra 2], [palavra 3]
PLATAFORMA: [Blog / LinkedIn / Instagram]

Faça:
1. Inclua a palavra-chave principal no título e primeiros 100 palavras
2. Use palavras-chave secundárias de forma natural
3. Melhore o gancho inicial
4. Adicione uma meta-description de 150 caracteres
5. Sugira 5 hashtags relevantes (se for rede social)

Mantenha o tom original. Não force palavras-chave.
```

## Prompt 9 — Responder Comentários e DMs

```
Escreva respostas para estes [X] comentários/mensagens no perfil de [Nome do Cliente].

CONTEXTO:
- Nicho: [nicho]
- Tom de voz: [tom]
- Serviços: [serviços principais]

COMENTÁRIOS/DMS:
1. "[Texto do comentário 1]"
2. "[Texto do comentário 2]"
3. "[Texto do comentário 3]"

Para cada um, escreva uma resposta que:
- Seja autêntica e humana (não corporativa)
- Agradeça quando relevante
- Responda a dúvida diretamente
- Quando pertinente, direcione para o CTA (link na bio, DM, WhatsApp)
- Máximo 3 linhas por resposta
```

## Prompt 10 — Gerar Ideias de Pauta para Blog/LinkedIn

```
Gere 10 ideias de artigos para [Blog/LinkedIn] para [Nome do Cliente].

CONTEXTO:
- Nicho: [nicho]
- Público: [público-alvo]
- Palavra-chave principal do negócio: [palavra-chave]
- Objetivo: [autoridade / SEO / geração de leads]

Para cada ideia:
- Título (com potencial SEO e curiosidade)
- Ângulo diferente dos conteúdos genéricos do nicho
- Palavra-chave foco
- Tipo de conteúdo (lista, how-to, opinião, caso de uso)

Priorize temas com alta intenção de busca e baixa competição.
```

## Prompt 11 — Diagnóstico Rápido do Perfil

```
Analise este perfil de [Instagram/LinkedIn] e faça um diagnóstico:

DADOS DO PERFIL:
- Nicho: [nicho]
- Bio atual: [bio]
- Últimos 5 posts (temas): [lista]
- Métricas médias: [engajamento, alcance]
- Objetivo: [objetivo]

Me dê:
1. Pontos fortes do perfil
2. Pontos fracos / o que está faltando
3. 5 melhorias prioritárias (em ordem de impacto)
4. Sugestão de nova bio (máximo 150 caracteres)
5. 3 tipos de conteúdo que funcionariam bem para este nicho

Seja específico e direto. Sem elogios vagos.
```

## Prompt 12 — Follow-up de Proposta

```
Escreva uma mensagem de follow-up para [Nome do Lead] que recebeu minha proposta há [X dias] e não respondeu.

CONTEXTO:
- Proposta enviada: [Pacote X — R$ X/mês]
- Reunião foi em: [data]
- Principal problema dele: [problema]
- Tom da nossa conversa: [amigável / formal / técnico]

A mensagem deve:
- Ser curta (máximo 4 linhas)
- Não parecer desesperada
- Reforçar 1 benefício específico para o problema dele
- Ter CTA claro (pergunta simples, não "você decidiu?")
- Tom: humano, direto, sem pressão

Gere 2 versões: uma para WhatsApp e uma para e-mail.
```
